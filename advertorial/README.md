# Standby House — Advertorial

Landing page promocional (advertorial) para [standbyhouse.com](https://standbyhouse.com/).

## Conteúdo

- Urgência (barra de alerta, countdown, stock da mala grátis)
- História de apagão + necessidade de proteção
- Kits Standby House com CTA para o site
- Oferta: **mala de emergência grátis** com o kit
- Reviews, comparação e FAQ
- Imagens, vídeo e GIF de atmosfera

## Correr localmente

```bash
cd advertorial
python3 -m http.server 8765 --bind 127.0.0.1
```

Abrir `http://127.0.0.1:8765`
